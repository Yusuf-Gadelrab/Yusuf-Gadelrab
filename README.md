## Projects worth a look

- **[adaptive-cs-tutor](https://github.com/Yusuf-Gadelrab/adaptive-cs-tutor)** — diagnostic concept-graph tutor for intro CS; a quiz marks shaky concepts, graph propagation flags at-risk topics, and a bilingual explainer covers each one
- **[prometheus-tutor](https://github.com/Yusuf-Gadelrab/prometheus-tutor)** — prerequisite-graph diagnostic with a local Qwen3 model explaining concepts in English or Arabic; runs offline
- **[dira](https://github.com/Yusuf-Gadelrab/dira)** — zero-dependency security audit tool for codebases: secrets, dependency CVEs, misconfigurations, license risk, and SBOM output
- **[edgelog](https://github.com/Yusuf-Gadelrab/edgelog)** — trade journal analyzer that computes expectancy, win rate, profit factor, and drawdown from a CSV
- **[eventreels](https://github.com/Yusuf-Gadelrab/eventreels)** — local ffmpeg pipeline that turns raw event footage into a 9:16 highlight reel using scene detection and audio-energy analysis
- **[IntakeKit](https://github.com/Yusuf-Gadelrab/IntakeKit)** — my own early-stage prototype for normalizing nonprofit intake forms. Unpublished, with no users or traction yet.
