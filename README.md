# Yusuf Gadelrab

BS Computer Science undergraduate at San José State University, Applied Mathematics track, expected May 2028.

I work mostly on backend systems, data pipelines, and AI tooling — turning messy text into structured data, running language models locally, and building teaching tools for intro computer science.

## What I'm interested in

- **Backend** — Python services, APIs, and parsers that hold up on real inputs
- **Data** — schema design, normalization, and getting unstructured messages into queryable records
- **AI tooling** — retrieval, local/offline language models, and evaluation for education use cases
