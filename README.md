# Hey, I'm Yusuf 👋

CS at San José State University. I build in public and ship tools I actually use myself.

## Building now

- 🎞️ **[EventReels](https://github.com/Yusuf-Gadelrab/eventreels)**: drop in raw event footage, get back a finished 9:16 highlight reel. The pipeline watches (scene detection) and listens (loudness analysis), picks the best seconds, and cuts the reel. 100% local ffmpeg, zero API keys.
- 📈 **[EdgeLog](https://github.com/Yusuf-Gadelrab/edgelog)**: a trade journal analyzer that tells you if you actually have an edge. Expectancy in R, profit factor, drawdown, edge by setup, and a plain-English verdict. I run my own trades through it.
- 🌍 **[EcoImpact](https://github.com/Yusuf-Gadelrab/ecoimpact)**: a trash map with a "world fixed" meter. Report litter, claim cleanups, log eco actions, and watch quantified impact (kg waste, kg CO₂e) climb.
